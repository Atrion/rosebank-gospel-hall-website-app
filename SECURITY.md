# Security

If you find a security problem in this app, please report it privately instead of opening a public issue.
Use the "Report a vulnerability" button on the repository's Security tab, or contact
[From Gravel Hill Enterprises](https://fromgravelhill.ca/).

The app has no accounts and stores no personal information. It reads public content from
rosebankgospelhall.ca and keeps saved posts and settings on the device only.
